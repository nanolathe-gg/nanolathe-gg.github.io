Game data ownership

You need an installed Total Annihilation folder containing the original HPI archives. Full-game data is separate from the engine and the browser demo.

Get Total Annihilation from GOG or Steam, or use your original CDs, then install the game. You need the installed files, not just the store installer or a CD image.

View on GOGView on Steam

On Mac or Linux, bring an installed Windows game folder from another computer or a Wine/CrossOver installation. Nanolathe itself runs natively.
