# Installer source fixtures

These MIT-licensed Nanolathe launcher resources mirror `tools/installer/macos`
and `tools/installer/windows` in the engine repository. Offline installer tests
package them in authored source archives to verify copying and shortcut refresh.
Refresh them alongside the public scripts and their mirrored contract tests.
They are test inputs; real installations fetch resources from the resolved engine
commit. The icon uses the website green N mark, copyright 2026 Nanolathe
contributors.
