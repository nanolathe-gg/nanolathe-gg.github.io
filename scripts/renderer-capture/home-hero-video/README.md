# Silent living-base hero

The homepage plays a 12-second, 720-frame, 60 FPS native modern GPU recording of
an ARM base defending against CORE units on Greenhaven. The fixed camera keeps
the scene calm while original units patrol, turrets track, a fighter passes,
projectiles and explosions run, the Kbot Lab produces Peewees, and the commander
constructs a wind generator. This is staged footage, with normal engine behavior.

Production engine: `e2ac78cda2a19ff77fb8ee04a6ed32fc8f2e8819`.
Isolated capture branch: `capture/homepage-modern-hero`, final source
`51d69275` (the full revision is in `manifest.json`). The current shared main
`33abd56e` has no differences from the production pin in renderer, client, detail
loader or film code. Production simulation, shaders, coefficients and runtime
defaults are untouched. The local capture branch must not be merged or pushed.

## Native scene and evidence

`hero.json` uses seed 7, 60 lead-in ticks, a fixed 2× camera, and the production
film route. `NANOLATHE_HERO_COMPOSITION=base` selects the local composition rather
than the standard film roster: original ARM lab, solar, radar, laser tower,
commander, Bulldog, Stumpy, Flash and Zeus, four original CORE ground units, and
one patrolling ARM fighter. Small footprint clearings remove nine destructible
feature anchors and their successors through the feature lifecycle, preserving
indestructible features. This is staging, not a gameplay tree-clearing claim.

The fixture queues ordinary ground/air patrols, lab construction and mobile
construction. Original COB scripts, pathfinding, economy, weapons and effects
run through the ordinary Session. Its original offscreen commanders also remain;
the complete evidence includes their activity. The visible wind generator
finishes during the clip. Native frame evidence records position changes,
construction progress and projectiles rather than inferring motion from a video.

Actual Metal on Apple M3 Pro, AA, enhanced rendering, interpolation, unit/feature
shadows, all modern effect controls and normal 100% strengths are enabled by the
production film path. Every frame's recorded drawlist uses 2347 genuinely
synthesized 64×64 terrain tiles and synthesized feature sprites. Missing/shadow
variants retain the production fallback. Camera magnification is separate from
the verified 2× art synthesis. Lighting is generated by actual engine effects;
626 frames contain ground lights and 692 contain live projectiles.

The authoritative simulation stays at 30 Hz. Each interval is rendered at
fractions 0 and 0.5, with publication ticks 61–420. The first frame samples the
60–61 interval at fraction 0. `NANOLATHE_HERO_BATCH=1` repeats the unchanged film
frame body inside one Draw callback to avoid hidden macOS window callback stalls.
The film cursor still owns all ticks/fractions; there is no wall-clock sampling,
speed change, invented pose or optical frame interpolation.

`capture.log` contains loader/staging/census output. `frame-proof.jsonl.gz`
contains all 720 read-only backend, artwork, state, GPU, unit and construction
observations. `native-frames.json` identifies every native PNG, viewport RGBA,
full-surface RGBA and committed-state hash. A second native run reproduces the
first five PNGs, surface hashes and state hashes exactly. Raw frames and the
binary stay in the task's sibling `capture-home-hero/`, outside the website.

## Export and browser behavior

The production clean-film crop copies the native 1280×880 world viewport from
the 1408×944 surface at `(128,32)` and silences messages. No further cropping,
resizing, retouching or compositing is applied. H.264/yuv420p, CRF 22 compression
is lossy; the video keeps the native size/rate, has no audio track and places its
metadata before frame data for streaming. `ffprobe.json` and
`video-decoded.framemd5` verify the complete 720-frame export.

The lossless still is native frame 120 (2 seconds), with exact decoded RGBA
equality. `manifest.json` identifies the script, producer binary, source files,
patch, native frames, still and served media. The binary was built before its
source-only commit, so its Git stamp is `02f9fa6b` with `modified=true`; the source
and binary hashes identify the exact producer. Retail archives, synthesis caches,
binaries and raw sequences are excluded from this repository.

The website loads and plays the silent loop when the picture is in view. It
pauses offscreen and in hidden tabs; an accessible button pauses or resumes it.
Reduced motion and data-saving preferences leave the still until explicit play.
No JavaScript, rejected autoplay and failed video loads retain a working still.
The previous static hero is retired from served files, with provenance retained
in `../home-hero/` and Git history. The recording has a normal loop cut; it does
not claim a seamless simulation loop.

## Reproduce locally

Start from an isolated engine checkout at the production revision, read its
`AGENTS.md`, `docs/FILM_CAPTURE.md` and installed Ebitengine headless-running skill,
then apply `capture-diagnostics.patch`. A macOS display context is required even
though the window stays hidden.

```sh
GOCACHE=/tmp/nanolathe-capture-gocache GOMAXPROCS=2 \
  go build -p 2 -o /tmp/nanolathe-home-hero-video ./cmd/nanolathe
caffeinate -u -t 60 &
XDG_CACHE_HOME=/tmp/nanolathe-home-hero-cache \
XDG_CONFIG_HOME=/tmp/nanolathe-home-hero-config \
EBITENGINE_GRAPHICS_LIBRARY=metal \
NANOLATHE_HERO_COMPOSITION=base NANOLATHE_HERO_BATCH=1 \
  /tmp/nanolathe-home-hero-video \
  --root "$HOME/TotalAnnihilation" --renderer modern --auto-remaster=true \
  --film /path/to/website/scripts/renderer-capture/home-hero-video/hero.json \
  --film-out /tmp/nanolathe-home-hero-video-frames --film-frames 720
ffmpeg -framerate 60 -i /tmp/nanolathe-home-hero-video-frames/frame%06d.png \
  -an -c:v libx264 -preset slow -crf 22 -pix_fmt yuv420p -movflags +faststart \
  hero-living-base-e2ac78cd.mp4
cwebp -lossless -exact -q 100 -m 6 \
  /tmp/nanolathe-home-hero-video-frames/frame000120.png \
  -o hero-living-base-e2ac78cd.webp
```
