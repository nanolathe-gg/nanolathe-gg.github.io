## Reproduce

Run from the worktree after copying the harness:

```
GOCACHE=/private/tmp/nanolathe-feature-v2-water/go-cache go run ./.capture-water -map 'Gods of War' -frames 180 -out /private/tmp/nanolathe-feature-v2-water/coast
GOCACHE=/private/tmp/nanolathe-feature-v2-water/go-cache go run ./.capture-water -scene metal -heading 0 -frames 180 -out /private/tmp/nanolathe-feature-v2-water/metal
```

The renderer runs hidden with bounded readbacks, all captures in one Draw callback, because presenting the hidden window between captures crashes the current macOS MetalDrawable integration. It produces every actual tick and encodes at 30 fps: playback is normal speed regardless of capture wall time. No performance benchmark was run.

MP4 encoding: `ffmpeg -framerate 30 -i <prefix>-%04d.png -c:v libx264 -crf 17 -preset slow -pix_fmt yuv420p -movflags +faststart <out>.mp4`. For metal add `-frames:v 120 -vf crop=720:400:220:140`. Posters use Pillow lossless WebP and the crop boxes above.

The unit/wind census confirms natural movement and wind changes. No engine production source changes; no merge, push, publish or website edits.
